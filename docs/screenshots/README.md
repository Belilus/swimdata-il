# Screenshots for GitHub Pages showcase

Captured from a **local** `build.sh` run over public ISA PDFs.

These images are committed so visitors can see the dashboard without downloading swimmer-level `data.js`.
Competition results are published by the ISA; many athletes are minors — raw PDFs and generated datasets remain out of git (see root `.gitignore`).

Regenerate after UI changes:

```bash
# from asaf-portfolio (playwright installed)
node scripts/capture-swimdata-screenshots.mjs   # if added, or re-run portfolio playwright script
```
